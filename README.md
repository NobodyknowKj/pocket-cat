# 🐈 Pocket Cat — گربه‌ی مجازی تلگرام

یک بات تلگرامی فارسی که به کاربر اجازه می‌دهد از یک گربه‌ی مجازی با **شخصیت، حافظه و زندگی مستقل** مراقبت کند.

گربه فقط مجموعه‌ای از دکمه‌ها نیست — گاهی بازیگوش است، گاهی خواب‌آلود، گاهی دنبال نوازش می‌گردد و گاهی ترجیح می‌دهد در گوشه‌ای بخوابد.

> **اصول:** بدون احساس گناه، بدون جریمه‌ی غیبت، بدون فشار برای ورود روزانه، بدون پرداخت واقعی.

## ✨ ویژگی‌ها

| بخش | توضیح |
|---|---|
| 🐾 شروع | پیام خوشامد دقیق سناریو + انتخاب نام (پیش‌فرض: موچی) + حالت «نگاه کردن» |
| 🏠 صفحه‌ی اصلی | نام، صمیمیت، گرسنگی٪، انرژی٪، شادی٪، وضعیت، محل + ۸ دکمه |
| 🍗 غذا دادن | ماهی، مرغ، تشویقی، غذای معمولی — قیمت و اثر دقیق + واکنش داستانی + حالت سیری |
| 🫳 نوازش | ۴ حالت (خوشحال / بازیگوش / خواب‌آلود / بی‌حوصله) + کول‌داون ۶۰ ثانیه + در خواب بیدار نمی‌کند |
| 🧶 بازی | ۴ بازی: نخ و پنجه، شکار موش، قایم‌باشک، توپ رنگی — هر دور `session_id` یکتا |
| 💤 خواب | چرخه‌ی روزانه بر اساس زمان واقعی — انرژی در خواب +۱۲/ساعت |
| 🏠 خانه | ۶ بخش: خواب، پنجره، بازی، غذا، جعبه‌ی وسایل، گوشه‌ی سبز + خرید وسایل با اثر محتوایی |
| 🧠 حافظه | غذای موردعلاقه، بازی موردعلاقه، محل خواب، تعداد بازی، خاطرات — و استفاده‌ی واقعی در واکنش‌ها |
| 📖 خاطرات | فقط از اتفاقات واقعی ثبت‌شده (اولین غذا، اولین بازی، اولین خواب و...) — بدون خاطره‌ی جعلی |
| 🎲 اتفاق تصادفی | جعبه، پرنده، گم شدن توپ، کشف وسیله — متنوع و کم‌تکرار |
| 🛒 فروشگاه | خوراکی، اسباب‌بازی، خانه، تزئینی — فقط با سکه‌ی بازی |
| 🎯 مأموریت | روزانه و کاملاً اختیاری — بدون جریمه‌ی غیبت و بدون از دست رفتن زنجیره |
| 🔔 اعلان | پیش‌فرض خاموش/محدود، کاملاً قابل خاموش/روشن |

## 🚀 نصب و اجرا

### ۱. ساخت بات در BotFather

1. در تلگرام به `@BotFather` پیام بده و `/newbot` را بفرست.
2. یک نام و یوزرنیم برای بات انتخاب کن (مثلاً `PocketCatBot`).
3. توکنی که BotFather می‌دهد را کپی کن — **هرگز آن را در گیت کامیت نکن.**

### ۲. نصب

```bash
cd pocket-cat
python3 -m venv .venv
source .venv/bin/activate   # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
```

### ۳. تنظیم توکن

```bash
cp .env.example .env
# فایل .env را باز کن و توکن را بگذار:
# TELEGRAM_BOT_TOKEN=123456789:AA...
```

یا مستقیم با متغیر محیطی:

```bash
export TELEGRAM_BOT_TOKEN="توکن‌تو"
```

### ۴. اجرا

```bash
python3 main.py
```

بات با `polling` اجرا می‌شود. در تلگرام بات را باز کن و `/start` بزن.

## 💰 اقتصاد بازی (دقیق)

### مقادیر اولیه

| متغیر | مقدار |
|---|---|
| گرسنگی | ۳۰ |
| انرژی | ۸۰ |
| شادی | ۶۵ |
| صمیمیت | ۱۰ |
| سکه | ۱۰۰ |
| XP | ۰ |
| سطح | ۱ |

### نرخ‌های زمانی (بر اساس زمان واقعی، فقط هنگام تعامل)

| متغیر | نرخ |
|---|---|
| گرسنگی | +۴ / ساعت |
| شادی (فقط اگر بیدار) | −۱ / ساعت |
| انرژی (بیداری) | −۲ / ساعت |
| انرژی (خواب) | +۱۲ / ساعت |
| انرژی (استراحت) | +۵ / ساعت |

همه در بازه‌ی `0–100` محدود (clamp) می‌شوند. گربه هرگز نمی‌میرد و غیبت هیچ جریمه‌ای ندارد.

### موجودی اولیه

سکه ۱۰۰، غذای معمولی ۳، تشویقی ۱، توپ ۱، تخت ۱.

### قیمت غذاها

| غذا | قیمت | کاهش گرسنگی |
|---|---|---|
| 🥣 غذای معمولی | ۸ سکه | ۲۵ |
| 🍗 مرغ | ۱۲ سکه | ۳۵ |
| 🐟 ماهی | ۱۵ سکه | ۴۰ |
| 🥛 تشویقی | ۶ سکه | ۱۰ |

اثر غذا فقط تا صفر — منفی نمی‌شود.

### تعامل‌ها

| تعامل | هزینه | تغییر | پاداش |
|---|---|---|---|
| نوازش | رایگان | شادی +۴، صمیمیت +۱ | — |
| بازی موفق | انرژی −۱۰ | شادی +۱۲، صمیمیت +۲ | ۵ سکه + ۳ XP |
| بازی ناموفق | انرژی −۵ | شادی +۳، صمیمیت +۱ | ۲ سکه + ۱ XP |

### قوانین بازی

- انرژی < ۱۰ → بازی شروع نمی‌شود.
- گرسنگی ≥ ۹۰ → بازی شروع نمی‌شود.
- احتمال موفقیت پایه ۷۰٪، انرژی < ۲۵ → ۵۰٪.
- هر دور `session_id` یکتا دارد؛ کلیک تکراری پاداش دوباره نمی‌دهد.
- نتیجه‌ی بازی‌های انتخابی (برنده) هنگام شروع ثبت می‌شود.

### سقف درآمد (ضد فارم)

- حداکثر **۱۰ دور پاداش‌دار** در ۲۴ ساعت شناور (زمان سرور).
- حداکثر **۵۰ سکه** از بازی در ۲۴ ساعت.
- ورود، منو و نوازش تکراری سکه نمی‌دهند.

### سطح

فرمول: `XP_next = 10 × (L + 1)` — سطح ۱→۲ = ۲۰ XP، ۲→۳ = ۳۰ و...

با هر ارتقا: پیام ویژه + واکنش جدید + **۱۰ سکه**. XP اضافه حفظ می‌شود و چند سطح در یک بار حساب می‌شود.

### فروشگاه MVP

| وسیله | قیمت | اثر |
|---|---|---|
| 🎨 توپ رنگی | ۲۰ | باز کردن تنوع بازی |
| 🐭 موش پارچه‌ای | ۳۵ | باز کردن واکنش ویژه |
| 🛏️ بالشت نرم | ۴۰ | باز کردن واکنش خواب جدید |
| 📦 جعبه‌ی مقوایی | ۲۵ | باز کردن رویداد جعبه |
| 🌳 درخت گربه | ۸۰ | باز کردن محل جدید خانه |

اثر وسایل = باز کردن محتوا، نه ضریب قدرت. خرید دائمی، بدون فروش مجدد.

## 🔒 امنیت و قوانین فنی

- توکن فقط از `TELEGRAM_BOT_TOKEN` (env) — بدون هاردکد.
- محاسبات اقتصادی سمت سرور؛ هیچ مبلغی از کلاینت پذیرفته نمی‌شود.
- خرید / کسر موجودی / ثبت تراکنش در یک تراکنش DB.
- هر عملیات پاداش‌دار `id` یکتا دارد.
- هیچ مقدار منفی برای سکه / XP / غذا / صمیمیت مجاز نیست.
- سقف روزانه با تراکنش/قفل کنترل می‌شود.
- زمان سرور مبنای محاسبات است.
- `/start` تکراری هرگز ریست نمی‌کند.
- در صورت خطا، بات پیام فارسی قابل‌فهم نشان می‌دهد و داده را خراب نمی‌کند.
- حافظه فقط داده‌ی بازی را نگه می‌دارد — هیچ داده‌ی خصوصی کاربر جمع‌آوری نمی‌شود.
- کاربر می‌تواند هر زمان اعلان‌ها را خاموش یا داده‌اش را پاک کند.
